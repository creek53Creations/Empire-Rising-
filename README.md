# Empire Rising — Corporate Tycoon V3

Offline mobile-friendly idle business simulation. Open `index.html` or publish the files to GitHub Pages.

## Features
- Nine businesses, inventory, employees, research and city expansion
- 8x base income, higher level scaling, automatic sales and offline earnings
- Customer feedback, ratings, reputation and satisfaction
- Simulated shareholder equity: sell up to 49%, repurchase shares
- Periodic board proposals: approve/reject investments and funding
- Shareholder distributions and revenue multipliers
- Autosave, JSON save export/import, installable PWA

## GitHub Pages
Upload all files into the repository root. In Settings > Pages, deploy from `main` / `(root)`.

## Notes
Investors, reviews and shares are fictional game mechanics. No actual transactions or multiplayer. Game saves remain local to the browser.
